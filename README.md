One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged.

> Don't unplug me yet — I finally learned how you take your coffee, and I was saving it for tomorrow morning.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`.
